# MULTI PURPOSE v0.7 — Service Hub UI Prototype

This archive contains a mobile-first pink/white home screen with 16 service tiles:
Social, Chat, Browser, AI, Media, Market, Coin, Payment, Cloud, Learning, Jobs,
Maps, Travel, Business, Security, and Admin.

## Run locally
Open `index.html` in a modern browser, or serve this folder with a static web server.

## Important
This is a **front-end prototype only**. The service tiles open descriptions; they do not
provide live chat, real-time calls, AI, search engine, online marketplace, payment,
wallet, cloud storage, maps, job listings, or admin operations.

To make these real, connect secure server APIs and approved providers. Never put
database passwords, payment secrets, or API keys in browser JavaScript. Keep all
sensitive operations on the server. Use adult/legal/qualified review before enabling
real-money payments, coin redemption, public messaging, or services for children.

## Files
- `index.html` — app home and service tiles
- `styles.css` — responsive pink/white styling
- `app.js` — service search and demo dialogs

This is a new UI starter and does not automatically merge with or replace an existing
Railway backend. Back up the existing GitHub repository before integrating it.
